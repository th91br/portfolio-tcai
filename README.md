# Thiago Cassol Antunes — Portfólio Profissional (TCAI)

Plataforma institucional e portfólio de alta performance de **Thiago Cassol Antunes**, especialista em desenvolvimento de software, aplicações web de alta conversão, SaaS escaláveis e automações com Inteligência Artificial.

---

## ⚡ Tecnologias & Arquitetura

- **Frontend Core:** [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build & Bundler:** [Vite](https://vitejs.dev/)
- **Estilização & Design System:** [Tailwind CSS](https://tailwindcss.com/)
- **Experiência 3D & Efeitos:**
  - [Three.js](https://threejs.org/) — Matriz cibernética interativa em 3D
  - [GSAP](https://gsap.com/) + [@gsap/react](https://github.com/greensock/react) — Tipografia 3D interativa com decodificador e efeito de onda
  - [Framer Motion](https://www.framer.com/motion/) — Empilhamento de cards (Sticky Deck) e letreiro infinito contínuo 24/7
- **Ícones & Vetores:** [Lucide React](https://lucide.dev/)

---

## 🚀 Como Rodar Localmente

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/SEU_USUARIO/portfolio-tcai.git
   cd portfolio-tcai
   ```

2. **Instalar as dependências:**
   ```bash
   npm install
   ```

3. **Iniciar o ambiente de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Compilar para produção:**
   ```bash
   npm run build
   ```

## 🌐 Deploy na Vercel

O projeto está 100% pronto e configurado para deploy com 1 clique na Vercel:
- **Framework Preset:** Vite
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
- Configuração SPA automática inclusa no arquivo `vercel.json`.
